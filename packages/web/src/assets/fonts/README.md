# Vendored font

`caveat-latin-500-normal.woff2` and `caveat-latin-ext-500-normal.woff2` are the Caveat
typeface (weight 500, Latin and Latin Extended subsets), copyright 2014 The Caveat Project
Authors, licensed under the SIL Open Font License 1.1. The licence text is in
[`Caveat-OFL.txt`](Caveat-OFL.txt). The files were taken unmodified from the
`@fontsource/caveat` package, version 5.3.0.

The app uses Caveat only to draw a typed signature. It is bundled so the app never loads a
font from another origin.
